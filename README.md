# HustleHub

A first Expo + React Native prototype for a Namibia-focused side-hustle marketplace.

## Included in this prototype
- Premium navy and gold visual direction
- Opportunity feed with search and category filters
- Demo listing detail popups
- Local demo listing form
- Profile placeholder

## Run the app
1. Install Node.js on a computer or use an Expo-compatible cloud development environment.
2. In this project folder run `npm install`.
3. Run `npx expo start`.
4. Install Expo Go on your Android phone and scan the QR code.

## Important prototype notes
- Listings are sample data and are not verified jobs.
- New listings are held only in temporary app memory; they are not uploaded to a server.
- Login, database storage, messaging, moderation, payments and production security are not yet implemented.
- Before publishing, configure an EAS project, test on real devices, add privacy and safety policies, and complete Google Play requirements.

## Project structure
- `App.js` - main app screen and prototype interactions
- `app.json` - Expo app configuration
- `package.json` - dependencies and scripts
